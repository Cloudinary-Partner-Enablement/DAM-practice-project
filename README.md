# Meadowlane DAM practice project: check script

1. `npm install`
2. Set credentials: `export CLOUDINARY_URL=cloudinary://API_KEY:API_SECRET@CLOUD_NAME`
3. Follow the partner guide. When ready, run `node check.js`.

Requires Node 18 or later. Results are written to `results.json`.

Cloudinary team: edit `project-config.js` (asset `match` strings, usage end date). This script has not been run against a live account.
